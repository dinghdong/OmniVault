残余信任点说明
⚠
唯一残余信任：0G Router 路由决策信任路由
Router 决定将请求发送给哪个 Provider（我们指定了已验证的 provider_addr）
缓解：推理响应签名验证会直接失败，若 Router 篡改了响应或换了 Provider
∴ Router 只能选择不服务，无法静默伪造一个「看起来合法」的 TEE 推理结果
